# Fuentes de Conecta UNMSM

- `catalog.academico.json`: datos recuperados de fuentes web públicas y de documentos enviados por el equipo. Fuente y estado visibles. No garantiza convocatoria abierta.
- `catalog.demo.json` y `catalog.multifaculty.demo.json`: fixtures ficticias históricas **solo para pruebas**, nunca modo normal.
- `catalog.snapshot.json`: vacío histórico de pruebas.
- `discovered.pending.json`: se genera al ejecutar el explorador; no se publica sin revisión.
