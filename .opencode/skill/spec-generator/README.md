# Integración opcional de OpenCode

En el screenshot original esta ruta es un **enlace simbólico** a `.claude/skills/spec-generator`.

El equipo utiliza principalmente Cursor, por lo que esta integración **no es necesaria para construir Conecta**. Si instalan OpenCode, copien `SKILL.md` y `spec-template.md` desde la carpeta `.claude/skills/spec-generator/` a esta carpeta. En Windows es más fiable copiar que depender de symlinks extraídos de un ZIP.

Mantener `.claude/skills/spec-generator/SKILL.md` como fuente única de verdad; si hay copia, sincronizarla tras cambios.
